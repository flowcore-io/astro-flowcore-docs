---
title: 5 Minute Tutorial
description: Publish and consume a typed Flowcore event with Pathways.
---

This tutorial creates one event contract, publishes an event, and prepares the same handler for local or managed delivery.

## Prerequisites

- A Flowcore tenant
- A Flowcore API key
- Bun, Node.js, or Deno

## Install Pathways

```sh
bun add @flowcore/pathways zod
```

## Define the event contract

```typescript
import { PathwaysBuilder } from "@flowcore/pathways"
import { z } from "zod"

const pathways = new PathwaysBuilder({
  baseUrl: "https://api.flowcore.io",
  tenant: process.env.FLOWCORE_TENANT!,
  dataCore: "todo-app",
  apiKey: process.env.FLOWCORE_API_KEY!,
  runtimeEnv: process.env.NODE_ENV === "production" ? "production" : "development",
  pathwayName: "todo-service",
  autoProvision: { pathway: true },
  managedConfig: {
    endpointUrl: "https://your-app.example/api/flowcore",
    authHeaders: {
      "X-Webhook-Secret": process.env.FLOWCORE_WEBHOOK_SECRET!,
    },
  },
})

pathways
  .register({
    flowType: "todo",
    eventType: "created.0",
    schema: z.object({
      id: z.string(),
      title: z.string(),
    }),
  })
  .handle("todo/created.0", async (event) => {
    console.log("todo received", event.eventId, event.payload)
  })
```

In development, Pathways uses a local virtual pump. In production, it defaults to managed delivery. Shared Data Core, Flow Type, and Event Type resources auto-provision; `autoProvision.pathway: true` also registers the named managed pathway.

## Publish an event

```typescript
await pathways.write("todo/created.0", {
  data: {
    id: crypto.randomUUID(),
    title: "Try Flowcore Pathways",
  },
})
```

Keep API keys and webhook secrets in environment variables. Do not commit them.

## Start delivery

At application startup, call:

```typescript
await pathways.startPump()
```

Development starts the local pump. Production managed mode provisions the configured resources but does not start an in-process pump; Flowcore delivers to `managedConfig.endpointUrl`.

Expose that endpoint with `PathwayRouter`, as shown in the [Pathways guide](/guides/flowcore-pathways/#webhook-integration). Return a successful response only after the handler completes.
