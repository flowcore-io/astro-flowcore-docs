---
title: Get Resources
description: List and inspect Flowcore resources with the Flowcore CLI.
---

The CLI has explicit commands for each supported resource.

## Tenants

```sh
flowcore get tenant
flowcore get tenant example-tenant
```

## Data Cores

```sh
flowcore data-core list --tenant example-tenant
flowcore data-core get example-data-core --tenant example-tenant
```

## Flow Types

```sh
flowcore flow-type list \
  --tenant example-tenant \
  --data-core example-data-core

flowcore flow-type get users \
  --tenant example-tenant \
  --data-core example-data-core
```

## Event Types

```sh
flowcore event-type list \
  --tenant example-tenant \
  --data-core example-data-core \
  --flow-type users

flowcore event-type get user.created.0 \
  --tenant example-tenant \
  --data-core example-data-core \
  --flow-type users
```

Add `--json` where supported for machine-readable output. Run `flowcore <command> --help` for the exact options in your installed CLI version.
